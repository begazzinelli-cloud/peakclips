Política de Privacidade

Última atualização: 2 de outubro de 2026

O Peak Clips usa os YouTube API Services. Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube, e os dados são tratados também conforme a Política de Privacidade do Google (seção 5).

1. O que é o aplicativo

O Peak Clips é uma ferramenta pessoal, usada apenas pelo seu dono (Bernardo Gazzinelli), para publicar vídeos curtos nas contas oficiais do Peak Clips no Instagram e no YouTube. O aplicativo não tem outros usuários e não oferece cadastro.

2. Quais dados o aplicativo acessa

  • YouTube (YouTube API Services): envio de vídeos para o canal do próprio dono e leitura das estatísticas públicas desses vídeos (visualizações, curtidas, comentários).
  • Instagram (API oficial da Meta): publicação de Reels na conta do próprio dono e leitura das métricas desses posts.
  • O aplicativo não coleta, não armazena e não processa dados de terceiros: não lê dados de outros usuários, seguidores ou espectadores.

3. Como os dados são guardados

As credenciais de acesso (tokens) e as métricas ficam armazenadas apenas no computador do dono, fora de qualquer servidor público. Os vídeos ficam temporariamente num armazenamento privado do Google Cloud, só durante a publicação, e são apagados em seguida.

4. Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros.

5. YouTube e Google

Este aplicativo usa os YouTube API Services. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google. O acesso concedido pode ser revogado a qualquer momento em myaccount.google.com/permissions.

6. Exclusão de dados

Para apagar os dados guardados pelo aplicativo, basta revogar o acesso nas configurações da conta Google ou da Meta. As credenciais locais são apagadas em até 7 dias, e as métricas armazenadas são excluídas mediante pedido pelo e-mail abaixo.

Privacy Policy

Last updated: October 2, 2026

Peak Clips uses YouTube API Services. By using the application you agree to be bound by the YouTube Terms of Service, and data is also handled under the Google Privacy Policy (section 5).

1. What the application is

Peak Clips is a personal tool used only by its owner (Bernardo Gazzinelli) to publish short videos to the official Peak Clips accounts on Instagram and YouTube. The application has no other users and offers no sign-up.

2. Data the application accesses

  • YouTube (YouTube API Services): uploading videos to the owner's own channel and reading the public statistics of those videos (views, likes, comments).
  • Instagram (Meta's official API): publishing Reels to the owner's own account and reading the metrics of those posts.
  • The application does not collect, store or process third-party data: it does not read data from other users, followers or viewers.

3. How data is stored

Access credentials (tokens) and metrics are stored only on the owner's computer, not on any public server. Videos are stored temporarily in private Google Cloud storage only while being published, and are deleted right after.

4. Sharing

No data is sold, shared or transferred to third parties.

5. YouTube and Google

This application uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply. Granted access can be revoked at any time at myaccount.google.com/permissions.

6. Data deletion

To delete data kept by the application, revoke its access in the Google or Meta account settings. Local credentials are deleted within 7 days, and stored metrics are deleted upon request to the email below.
